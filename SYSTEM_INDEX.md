# InTheDeep — індекс систем і ключових тем

> **Призначення:** короткі стабільні коди для навігації Claude Code й автора між документами.
> **Статус:** індекс посилань; **НЕ** нове джерело правди й **НЕ** перелік додатково затверджених механік.
> **Оновлено:** 2026-11-08. Усі вказані нижче основні файли перевірено в репозиторії.

## Як читати коди

- `SYS-...` — геймплейна, технічна або прогресійна **система**.
- `WLD-...` — **світ**, геологія або екосистема.
- `NAR-...` — **сюжет / наратив**.
- `CRE-...` — **профіль істоти**.
- Код позначає **тему чи систему загалом**, не стверджує, що всі деталі вже затверджено.
- **ID рішення — інша сутність.** Наприклад, `MEC-027` у PDF Vizivalshik є номером *питання* про інвентар у його універсальній анкеті. У InTheDeep цей код **не призначено** жодному рішенню. Для рішень застосовувати правила з [DESIGN_DECISION_WORKFLOW.md](DESIGN_DECISION_WORKFLOW.md), лише коли реально заведено окремий запис.

## Пошук і посилання для Claude Code

1. Якщо в запиті є код (наприклад, `SYS-INV`), **спочатку знайти його тут** і прочитати тільки відповідний основний файл; додаткові залежності читати за потреби.
2. Якщо є назва системи без коду — знайти назву в цій таблиці; не вигадувати новий ID для вже наявної теми.
3. Якщо питання стосується двох систем (наприклад, `SYS-INV` + `SYS-CNS`), відкрити обидва джерела, не переносити повний опис одного в інший.
4. У нових документах можна писати `SYS-INV` із посиланням на [основний файл](Mechanics/Inventory/INVENTORY_AND_LOGISTICS.md). Сам ID — **не гіперпосилання**; навігацію забезпечує цей індекс.
5. Якщо нова самостійна система отримує постійний основний документ, додати їй **новий, унікальний, короткий ID** в індекс. Старі коди не перейменовувати й не використовувати вдруге; при зміні шляху оновити посилання.
6. Не створювати дублікати файлів для ID, не змінювати затверджені рішення заради нумерації, не позначати чернетку як ухвалену.
7. Не читати весь індекс і всю документацію повторно для кожної дрібної зміни: використовувати його як маршрутизатор, коли потрібен пошук.
