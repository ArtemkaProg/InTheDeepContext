# Перелік змін і перевірок

## Замінити файлами з архіву
- `README.md` — навігація замість звіту про міграцію.
- `CONTEXT.md` — короткий огляд, коректні шляхи до профілів, без дублювання описів істот.
- `Concepts/World/WORLD_FOUNDATION.md` — принципи світу, відокремлені від конкретних істот.
- `Creatures/Klop/Klop.md` — профіль, рішення, пропозиції, відкриті питання, референс `6.png`.
- `Creatures/Endoceras/Endoceras.md`, `Creatures/Dunkleosteos/Dunkleosteus.md`, `Creatures/Omnidens/Omnidens.md` — профілі з правильними відносними посиланнями.

## Обережно
- `WORLD_AND_CREATURES.md` у ZIP — архівна заглушка. Замінювати оригінал тільки після перевірки, що не втрачено авторських деталей. Надійніший варіант — залишити оригінал у Git-історії й видалити його окремим комітом після review.
- Назву папки `Dunkleosteos` НЕ перейменовано: це окрема операція, яка потребує оновлення всіх посилань.
- `GAME_PLAN.md`, `CLAUDE.md`, інші механіки й референси не переписувалися.
- `CONTEXT.md` скорочено й реструктуровано: перед заміною переглянути `git diff`, бо вихідний документ значно довший і містить докладні механіки, які можуть потребувати окремих документів.

## Git
1. Розпакувати ZIP у корінь репозиторію.
2. `git diff --check`
3. `git diff -- README.md CONTEXT.md Concepts/World/WORLD_FOUNDATION.md Creatures/`
4. Перевірити старі посилання: `git grep -n 'WORLD_AND_CREATURES.md'`.
5. Після перевірки — окремий коміт.
