# Reference assets

The initial visual reference catalog uses Markdown-embedded images
hosted by NOAA source pages. This keeps the repository lightweight and
preserves links to the original descriptions and credits.

If local/offline references are needed: 1. Verify each image's reuse
conditions on its original page. 2. Download it into this folder. 3. Use
descriptive filenames, e.g. `Quiet-Abyssal-Plain.png`. 4. Keep a
source URL and credit in `REFERENCE_CATALOG.md`. 5. Replace the remote
image URL with a relative path such as
`![Description](references/abyssal_plain_noaa_2026.jpg)`.

Do not save images without their source and attribution.
